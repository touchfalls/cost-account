# Fortnite Locker Evaluator Bot 🎮

Асинхронный Telegram-бот на базе `aiogram 3.x`, который позволяет игрокам Fortnite оценить стоимость и редкость своего шкафчика (инвентаря).

## Основные возможности

*   **Epic Games OAuth Authorization:** Безопасная авторизация через Device Code (без передачи паролей) для чтения инвентаря игрока напрямую из Epic Games API.
*   **V-Bucks Valuation Engine:** Эвристический алгоритм, который оценивает суммарную стоимость косметических предметов (скинов, кирок, эмоций и т.д.) в V-Bucks с учетом актуальных рыночных расценок.
*   **Rarity Engine:** Уникальный алгоритм расчета «множителя редкости» для каждого предмета, основывающийся на его давности (Chapter/Season) и эксклюзивности.
*   **Regional Fiat Pricing (Алгоритм о рюкзаке):** Бот узнает страну аккаунта Epic Games и рассчитывает, сколько реальных денег (USD, RUB, TRY и т.д.) потребовалось бы на покупку такого количества V-Bucks. Расчет производится методом динамического программирования для поиска самой дешевой комбинации официальных паков V-Bucks.
*   **Telegram-интерфейс:** Красивый HTML-отчет с подробной статистикой по категориям и Топ-5 самых ценных/редких предметов инвентаря.

## Технологический стек

*   **Python 3.11+**
*   **Асинхронность:** `asyncio`, `aiohttp`, `aiogram`
*   **Валидация данных:** `pydantic v2`
*   **Пакетный менеджер:** `uv`
*   **Тестирование:** `pytest`
*   **API:** Epic Games API (Athena Profile, Account Info), Fortnite-API.com (каталог косметики)

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/touchfalls/cost-account.git
   cd cost-account
   ```

2. Настройте переменные окружения:
   Скопируйте пример конфига и вставьте свои ключи от Telegram и Epic Games:
   ```bash
   cp .env.example .env
   ```

3. Запустите бота с помощью `uv`:
   ```bash
   uv run python main.py
   ```

## Тестирование
Для запуска юнит-тестов (более 50 тестов для оценки, редкости, региональных цен и парсинга):
```bash
uv run pytest tests/ -v
```
